# Welcome to the Wang Lab at Princess Margaret Hospital

## What is this handbook?
This handbook serves as a guide for new and existing Wang Lab members. It provides essential information about lab policies, procedures, and resources to help you navigate your time in the lab effectively.

## If you are new to the lab
Please see the side bar for a list of topics covered in this handbook. If you are a new member, please start at the [onboarding page](transitions/onboarding.md).

## Adding content to the handbook
This handbook is a living document, and we encourage all lab members to contribute. If you have suggestions for new content or updates to existing content, please follow the instructions in the [README](https://github.com/wanglab-cns/handbook/) to add your contributions.
