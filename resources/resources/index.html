Overview

We use a variety of resources for our work, from remote clusters to data repositories. This page provides an overview of the resources we use and how to access them.

Communication

Slack

We use slack for communication within the lab. Currently, we are part of the BHK lab Slack workspace. Please reach out to Farnoosh to be added to the workspace.

Code and Data Repositories

GitHub

We use GitHub to host our code. Please reach out to Farnoosh or Andrew to be added to the Wang Lab GitHub organization. We recommend that for any work done on the servers like nibi, you should use GitHub to store your code. This will make it easier to share your work with others in the lab and to keep track of changes.

Lab Management

Google Drive

We use a shared Google Drive to store lab documents and data. Please reach out to Farnoosh to be added to the Wang Lab Google Drive.

Here, you can find presentations, grants, and other documents that are relevant to the lab.

Computing Resources

We use both the Digital Research Alliance of Canada (DRAC) and the HPC4Health (H4H) for computing needs. Please see the following pages for more information on how to access these resources:

  • Digital Research Alliance of Canada (DRAC)
  • HPC4Health (H4H)
